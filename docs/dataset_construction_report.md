# 数据集构建简要报告

## 1. 目标

本项目首先构建面向电池材料的单相 XRD 数据集，用于训练物相识别、晶系识别和晶格参数回归模型。数据来源为 Materials Project，谱图由晶体结构模拟生成，并加入实验中常见的扰动。

## 2. 材料范围

数据集聚焦电池相关材料，而不是泛化到所有无机材料：

| 类别 | 说明 |
| --- | --- |
| 正极材料 | 层状氧化物、尖晶石、磷酸盐等 |
| 负极材料 | 石墨、硅、钛酸锂等 |
| 固态电解质 | 氧化物、硫化物、磷酸盐等 |
| 参考相/副产物 | 常见分解产物和参比物相 |

当前为课程项目规模的 pilot 数据库，目标是可复现、可训练、可扩展。

## 3. 下载与筛选

下载脚本：`src/download_materials.py`

筛选策略：

- 按材料类别和化学体系收集候选结构。
- 优先保留稳定、低 `energy_above_hull`、有序结构。
- 使用 subclass 配额和 space group 轮转，避免某一类材料过度集中。
- 每个物相标签最多保留 3 个 Materials Project 结构变体。

下载结果：

| 项目 | 数量 |
| --- | ---: |
| 材料记录 | 211 |
| 物相标签 | 207 |
| 有序结构 | 211 |

未达到 300 个材料的原因是当前 battery-only 检索范围内唯一候选本身有限，而不是 API 下载失败。

## 4. 标签设计

物相标签采用：

```text
phase_label = formula_pretty + "_" + spacegroup_symbol
```

这种标签比单独使用化学式更严格，可以区分不同晶型；也比正极/负极这类应用标签更符合 XRD 物相识别任务。

## 5. 单相数据规模

数据目录：`data/processed/single_phase`

| 划分 | 样本数 | 每类样本数 | 用途 |
| --- | ---: | ---: | --- |
| `train.npz` | 31,050 | 150 | 训练 |
| `val.npz` | 4,140 | 20 | 验证与阈值选择 |
| `test_normal.npz` | 4,140 | 20 | 常规测试 |
| `test_hard.npz` | 4,140 | 20 | 强扰动鲁棒性测试 |

总样本数为 43,470。每条谱图包含 3501 个 2θ 网格点，范围为 10-90 度。

## 6. XRD 生成流程

基础谱图使用 `pymatgen.analysis.diffraction.xrd.XRDCalculator` 生成，辐射源为 Cu K-alpha。

主要增强包括：

- 晶格参数微扰；
- pseudo-Voigt 峰形展宽；
- 峰强随机扰动；
- 全局峰位偏移；
- 多项式背景；
- 高斯白噪声；
- 强度缩放与归一化。

`test_hard` 使用更强的峰位偏移、噪声、背景和峰宽扰动，用来测试模型在更困难实验条件下的稳定性。

## 7. 保存字段

核心字段：

| 字段 | 含义 |
| --- | --- |
| `X` | XRD 强度序列 |
| `y` | 物相标签 |
| `crystal_system_y` | 晶系标签 |
| `lattice_params` | `a,b,c,alpha,beta,gamma` |
| `peak_hkls` | Bragg 峰 Miller 指数 |
| `peak_2theta` | 参考峰位 |
| `peak_mask` | 有效峰掩码 |

这些字段支持物相分类、晶格参数回归和基于 Bragg 定律的物理一致性评估。

## 8. 局限性

- 当前是电池材料 pilot 数据库，不是完整无机材料数据库。
- 数据主要为模拟 XRD，不能完全替代真实实验谱图。
- 尚未显式建模 preferred orientation。
- 峰宽模型还不是完整 Caglioti 模型。
- 当前测试集主要是谱图扰动测试，尚未完全做结构 holdout。

## 9. 小结

该数据集的核心价值是：建立了可追溯、面向电池材料、带物理元数据的合成 XRD 数据基础，为后续单相识别、混相识别、晶格回归和物理一致性评价提供统一输入。
