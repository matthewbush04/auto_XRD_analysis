数据集技术亮点简述
==================

1. 面向电池材料场景
------------------

项目没有直接使用通用无机材料全集，而是围绕电池材料 XRD 识别构建数据范围，覆盖正极、负极、固态电解质和常见参考相/副产物。

2. 物相级标签
-------------

标签定义为：

phase_label = formula_pretty + "_" + spacegroup_symbol

这样可以区分不同晶型，比单独使用化学式或正极/负极这类应用标签更适合 XRD 物相识别。

3. 可控下载策略
---------------

下载阶段先收集候选材料，再按稳定性、能量、材料子类和空间群多样性进行筛选。每个物相标签最多保留 3 个结构变体，避免数据被少数材料族主导。

4. 可追溯元数据
---------------

每条材料记录保存 Materials Project 编号、化学式、物相标签、类别、空间群、晶系、能量、密度、CIF 路径和结构路径。因此，每条模拟 XRD 都可以追溯到原始晶体结构。

5. 基于晶体结构生成 XRD
----------------------

基础峰位和峰强由 pymatgen 的 XRDCalculator 计算，辐射源为 Cu K-alpha，2θ 范围为 10-90 度。这保证谱图的基础信号来自真实晶体结构。

6. 实验启发的数据增强
--------------------

增强内容包括晶格扰动、pseudo-Voigt 峰形、峰强扰动、全局峰位偏移、多项式背景、高斯噪声、强度缩放和归一化。这些扰动对应真实 XRD 中常见的峰位偏差、峰展宽、背景漂移和噪声。

7. 普通测试与困难测试分离
------------------------

`test_normal` 使用接近训练集的扰动强度，评估常规泛化能力。`test_hard` 使用更强的峰位偏移、噪声、背景和峰宽扰动，评估鲁棒性。

8. 支持多任务学习
----------------

数据集中除 XRD 谱图和物相标签外，还保存晶系、晶格参数、Bragg 峰 hkl、参考峰位和峰掩码，可用于物相分类、晶格回归和 Bragg 定律误差评价。

9. 支持物理一致性评价
--------------------

模型预测晶格参数后，可以根据 Bragg 定律计算理论峰位，并与参考峰位比较，得到 Bragg 峰位平均绝对误差。该指标用于评价模型输出是否具有物理一致性。

10. 当前规模
------------

- 材料记录：211
- 物相标签：207
- 合成 XRD 谱图：43,470
- 训练集：31,050
- 验证集：4,140
- 普通测试集：4,140
- 困难测试集：4,140

11. 局限性
----------

当前数据集是电池材料 pilot 数据库，尚不能代表完整材料空间；谱图为模拟数据，不能完全替代真实实验；preferred orientation 和完整仪器函数仍需后续扩展。

一句话总结
----------

本项目的数据阶段不仅生成了合成 XRD 谱图，还构建了一个可追溯、面向电池材料、支持多任务学习和物理一致性评价的数据基础。
